## Projet en cours de développement

Ce projet de jeu réalisé sur Godot sera un jeu du même style que Subway Surfers ou Temple Run mais dans un style différent.
En mélangeant des modèles 2D (crées par un artiste) dans un environnement 3D, on peut avoir un jeu en 2.5D.

Ce projet ne peut pas être exécuté en local pour le moment à cause de son instabilité.

### Fonctionnalités:
- Système de sauvegarde
- Course infinie
- Utilisation d'objets qui affectent la course

### Tester le projet:
ATTENTION: C'est un projet non terminé, il y a très probablement de nombreux bugs et la majorité des fonctionnalités ne sont pas disponible. 

- [Télécharger le dépôt git](https://github.com/kadthelad/jeu_de_course_infinie/archive/refs/heads/main.zip)
- [Télécharger Godot](https://godotengine.org/download/)
- Dézipper l'archive
- Lancer Godot
- Dans l'explorateur de projets (dans Godot) => cliquer sur "importer" et trouvez le dossier du projet
- Toujours dans l'explorateur de projets => Sélectionner le projet ("untitled_running_game") => cliquer sur "éxecution"
